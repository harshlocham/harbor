# Harbor docs (Mintlify)

This directory is the Mintlify documentation site (`docs.json` + MDX).

## Local

From the repo root:

```bash
pnpm docs:dev
pnpm docs:check
```

## Hosted

Connect this repository in [Mintlify](https://app.mintlify.com) with **subdirectory `docs`**. Full steps: [CONTRIBUTING.md — Publishing](../CONTRIBUTING.md#publishing-mintlify-hosting).
